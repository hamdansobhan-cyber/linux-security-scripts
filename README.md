# linux-security-scripts
Collection of Linux security and system administration scripts for cybersecurity learning.

## Scripts Included

### system_info.sh
Displays:
- Hostname
- Current user
- Operating system
- Kernel version
- CPU information
- Memory usage
- Disk usage

## Technologies Used
- Bash
- Linux Commands
- Shell Scripting

## How to Run

```bash
chmod +x system_info.sh
./system_info.sh
```

## Learning Objectives
- Linux system administration
- Bash scripting
- System monitoring
- Cybersecurity fundamentals
